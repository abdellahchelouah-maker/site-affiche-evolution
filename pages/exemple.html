Exemple : la reproduction du son

Un exemple complet de frise, de l’objet le plus ancien au produit du futur. Observez la structure de chaque étape plutôt que le sujet : c’est elle que vous devez reprendre pour votre objet.

Ceci est un exemple, pas un modèle à copier

Votre affiche porte sur un autre objet. Reprenez la méthode : étapes clés, ce qui change à chaque étape, type de solution, puis futur cohérent.

La structure d’une étape

Chaque étape contient…

  1. Nom et date de première fabrication (et inventeur si possible).
  2. Une image claire.
  3. Évolution du principe technique : comment ça marche, qu’est-ce qui change.
  4. Évolution ergonomique : taille, portabilité, commandes.
  5. Évolution esthétique : formes, matériaux, couleurs.
  6. Type de solution : non mécanisée → mécanisée → électrique → automatisée → informatisée.

Pourquoi ça marche ?

  • Même présentation pour toutes les étapes : on compare d’un coup d’œil.
  • Les mots clés du changement sont visibles (« numérique », « portable », « plastique »).
  • La solution technique est étiquetée : on voit les grandes ruptures.
  • Le futur reprend le même gabarit, ce qui montre sa cohérence.

Ce que cet exemple pourrait encore améliorer

Pour viser la meilleure évaluation, allez plus loin que cet exemple sur ces points :

  • Inventeurs : la rubrique « auteur » n’est pas renseignée partout. Votre affiche doit les citer (si possible).
  • Pourquoi ? : expliquez la raison de chaque changement (besoin, découverte scientifique, matériau, coût…), pas seulement le changement.
  • Développement durable : le produit du futur doit expliquer comment il réduit son impact (matériaux, énergie, durée de vie, recyclage).
  • Innovation majeure et fonctionnement plausible : le futur ne se limite pas à « un casque virtuel » : détaillez les composants et la commande.
  • Croquis : plusieurs croquis annotés plutôt qu’une image trouvée en ligne.
